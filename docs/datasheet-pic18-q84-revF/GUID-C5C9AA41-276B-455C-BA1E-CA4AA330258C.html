15.7.3 WDTPSH

WWDT Prescaler Select Register (Read-Only)
Note:
  1. The 18-bit WDT prescaler value, PSCNT[17:0] includes the WDTPSL, WDTPSH and the lower bits of the WDTTMR registers. PSCNT[17:0] is intended for debug operations and will be read during normal operation.
Name: WDTPSH
Address: 0x07B

Bit 76543210 
 PSCNTH[7:0] 
Access RRRRRRRR 
Reset 00000000 

Bits 7:0 – PSCNTH[7:0]  Prescaler Select High Byte(1)

The 18-bit WDT prescaler value, PSCNT[17:0] includes the WDTPSL, WDTPSH and the lower bits of the WDTTMR registers. PSCNT[17:0] is intended for debug operations and will be read during normal operation.
