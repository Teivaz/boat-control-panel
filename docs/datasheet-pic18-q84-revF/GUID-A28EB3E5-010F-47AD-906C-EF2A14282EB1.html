13.13.3 CRCCON2

CRC Control Register 2
Name: CRCCON2
Address: 0x359

Bit 76543210 
    DLEN[4:0] 
Access R/WR/WR/WR/WR/W 
Reset 00000 

Bits 4:0 – DLEN[4:0] Data Length

Denotes the length of the data word (n-1)
