10.5.5 NVMDAT

Nonvolatile Memory Data Register
Note: The individual bytes in this multibyte register can be accessed with the following register names:
  • NVMDATH: Accesses the high byte NVMDAT[15:8]
  • NVMDATL: Accesses the low byte NVMDAT[7:0]
