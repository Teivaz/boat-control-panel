14.2 Brown-out Reset (BOR)

The BOR circuit holds the device in Reset when VDD reaches a selectable minimum level. Between the POR and BOR, complete voltage range coverage for execution protection can be implemented. The BOR bit will be set to ‘0’ if a BOR has occurred.

The BOR module has four operating modes controlled by the BOREN Configuration bits. The four operating modes are:

  • BOR is always on
  • BOR is off when in Sleep
  • BOR is controlled by software
  • BOR is always off

Refer to the BOR Operating Modes table for more information.

A VDD noise rejection filter prevents the BOR from triggering on small events. If VDD falls below VBOR for a duration greater than parameter TBORDC, the device will reset. Refer to the “Electrical Specifications” chapter for more details.
