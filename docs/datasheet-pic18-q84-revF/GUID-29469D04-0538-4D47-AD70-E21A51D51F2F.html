14 Resets

There are multiple ways to reset the device:

  • Power-on Reset (POR)
  • Brown-out Reset (BOR)
  • Low-Power Brown-out Reset (LPBOR)
  • MCLR Reset
  • WDT Reset
  • RESET instruction
  • Stack Overflow
  • Stack Underflow
  • Programming mode exit
  • Memory Execution Violation Reset
  • Main LDO Voltage Regulator Reset
  • Configuration Memory Reset
