36.4.4 Client Mode Clock Configuration

In Client mode, SCK is an input and must be configured to the same polarity and clock edge as the host device. As in Host mode, the polarity of the clock input is controlled by the CKP bit and the clock edge used for transmitting data are controlled by the CKE bit.
