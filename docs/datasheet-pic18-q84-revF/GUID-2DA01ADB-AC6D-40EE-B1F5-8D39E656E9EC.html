16.13.12 DMAnDPTR

DMA Destination Pointer Register
Note: The individual bytes in this multibyte register can be accessed with the following register names.
  1. DMAnDPTRH: Accesses the high byte [15:8].
  2. DMAnDPTRL: Access the low byte [7:0].
