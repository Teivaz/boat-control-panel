9.7.7 POSTDEC

This is a virtual register. The GPR/SFR register addressed by the FSRx register is the target for all operations involving the POSTDECx register. FSRx is decrememted after the read or write operation.
Name: POSTDECx
Address: 0x4ED,0x4E5,0x4DD

Indirect Data Register with post decrement
