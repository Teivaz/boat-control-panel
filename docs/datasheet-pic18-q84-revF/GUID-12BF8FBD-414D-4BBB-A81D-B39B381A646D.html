16.13.4 DMAnBUF

DMA Data Buffer Register
Name: DMAnBUF
Address: 0x0E9

Bit 76543210 
 BUF[7:0] 
Access RRRRRRRR 
Reset 00000000 

Bits 7:0 – BUF[7:0] DMA Data Buffer

Description
These bits reflect the content of the internal data buffer the DMA peripheral uses to hold the data being moved from the source to destination.
