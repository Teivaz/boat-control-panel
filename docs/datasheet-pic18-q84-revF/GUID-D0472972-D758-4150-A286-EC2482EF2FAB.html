11.13.5 IVTLOCK

Interrupt Vector Table Lock Register
Note:
  1. The IVTLOCKED bit can only be set or cleared after the unlock sequence in IVT Unlock Sequence.
  2. If IVT1WAY = 1, the IVTLOCKED bit cannot be cleared after it has been set.
Name: IVTLOCK
Address: 0x459

Bit 76543210 
        IVTLOCKED 
Access R/W 
Reset 0 

Bit 0 – IVTLOCKED  IVT Registers Lock(1,2)

ValueDescription
1 IVTBASE Registers are locked and cannot be written
0 IVTBASE Registers can be modified by write operations
The IVTLOCKED bit can only be set or cleared after the unlock sequence in IVT Unlock Sequence. If IVT1WAY = 1, the IVTLOCKED bit cannot be cleared after it has been set.
