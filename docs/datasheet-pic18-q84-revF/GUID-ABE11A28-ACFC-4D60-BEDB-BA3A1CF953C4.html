38.8 Message Reception

The application has to configure the RX FIFO before it can be used for reception (see Receive FIFO Configuration). In addition, the application has to configure and enable at least one filter (see Filter Configuration).

The CAN FD Protocol Module continuously monitors the CAN bus. Messages that match a filter are stored in the RX FIFO pointed to by the filter (see Filtering a Received Message). The message data are stored in the receive message objects.
