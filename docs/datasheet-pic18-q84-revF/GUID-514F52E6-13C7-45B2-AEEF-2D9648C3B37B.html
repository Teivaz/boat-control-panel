16.13.7 DMAnSCNT

DMA Source Count Register
Note: The individual bytes in this multibyte register can be accessed with the following register names.
  1. DMAnSCNTH: Accesses the high byte [15:8].
  2. DMAnSCNTL: Access the low byte [7:0].
