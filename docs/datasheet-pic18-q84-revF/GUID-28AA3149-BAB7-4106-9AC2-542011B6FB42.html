38.13.19 CxTEFUA

CAN Transmit Event FIFO User Address Register
Note:
  1. The individual bytes in this multibyte register can be accessed with the following register names:
    • CxTEFUAT: Accesses the top byte TEFUA[31:24]
    • CxTEFUAU: Accesses the upper byte TEFUA[23:16]
    • CxTEFUAH: Accesses the high byte TEFUA[15:8]
    • CxTEFUAL: Accesses the low byte TEFUA[7:0]
  2. This register is not ensured to read correctly in Configuration mode and may only be accessed when the module is not in Configuration mode.

Bits 31:0 – TEFUA[31:0] Transmit Event FIFO User Address

A read of this register will return the address where the ntext event is to be read (FIFO tail).
The individual bytes in this multibyte register can be accessed with the following register names: CxTEFUAT: Accesses the top byte TEFUA[31:24] CxTEFUAU: Accesses the upper byte TEFUA[23:16] CxTEFUAH: Accesses the high byte TEFUA[15:8] CxTEFUAL: Accesses the low byte TEFUA[7:0] This register is not ensured to read correctly in Configuration mode and may only be accessed when the module is not in Configuration mode.
