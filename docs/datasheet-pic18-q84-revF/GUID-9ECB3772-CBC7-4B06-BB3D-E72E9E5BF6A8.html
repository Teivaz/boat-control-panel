37.5.18 I2CxADR2

I2C Address 2 Register
Name: I2CxADR2
Address: 0x0292

Bit 76543210 
 ADR[7:0] 
Access R/WR/WR/WR/WR/WR/WR/WR/W 
Reset 11111111 

Bits 7:0 – ADR[7:0]  I2C Client Address 2

NameDescription
7-bit Client/Multi-Host modes (MODE = 000 or 110): ADR[7:1]: 7-bit client address 2

ADR[0]: Unused; bit state is ‘don’t care’
7-bit Client/Multi-Host modes with Masking (MODE = 001 or 111): ADR[7:1]: 7-bit client address

ADR[0]: Unused; bit state is ‘don’t care’
10-bit Client mode (MODE = 010): ADR[7:0]: Eight Least Significant bits of the second 10-bit address
10-bit Client mode with Masking (MODE = 011): ADR[7:0]: Eight Least Significant bits of 10-bit address mask
