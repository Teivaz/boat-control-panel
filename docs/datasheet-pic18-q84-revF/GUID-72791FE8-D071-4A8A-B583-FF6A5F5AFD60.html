Introduction

The PIC18-Q84 microcontroller family is available in 28/40/44/48-pin devices for many automotive and industrial applications. The many communication peripherals found in the product family, such as Controller Area Network (CAN), Serial Peripheral Interface (SPI), Inter-Integrated Circuit (I2C), and two Universal Asynchronous Receiver Transmitters (UARTs), can handle a wide range of wired and wireless (using external modules) communication protocols for intelligent applications. Combined with the Core Independent Peripherals (CIPs) integration capabilities, this capacity enables functions for motor control, power supply, sensor, signal and user interface applications. Additionally, this family includes a 12-bit Analog-to-Digital Converter (ADC) with Computation and Context Switching extensions for automated signal analysis to reduce the complexity of the application.
