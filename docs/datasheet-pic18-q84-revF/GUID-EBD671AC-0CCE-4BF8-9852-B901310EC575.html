16.3.4.2 Stopping DMA Message Transfers

The DMA controller can stop data transactions by any of the following conditions:

  • Clearing the DGO bit
  • Hardware abort trigger, AIRQ
  • Source count reload
  • Destination count reload
  • Clearing the EN bit
