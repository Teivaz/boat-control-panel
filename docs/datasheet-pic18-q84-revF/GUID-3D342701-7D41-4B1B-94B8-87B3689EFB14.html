27.2.7 SMTxTMR

SMT Timer Register
Note: The individual bytes in this multibyte register can be accessed with the following register names:
  • SMTxTMRU: Accesses the upper byte TMR[23:16]
  • SMTxTMRH: Accesses the high byte TMR[15:8]
  • SMTxTMRL: Accesses the low byte TMR[7:0]
