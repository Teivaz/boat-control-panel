19.11 I2C Pad Control

For this family of devices, the I2C specific pads are available on RB1, RB2, RC3 and RC4 pins. The I2C characteristics of each of these pins is controlled by the RxyI2C registers. These characteristics include enabling I2C specific slew rate (over standard GPIO slew rate), selecting internal pull-ups for I2C pins, and selecting appropriate input threshold as per SMBus specifications.

Important: Any peripheral using the I2C pins reads the I2C input levels when enabled via RxyI2C.
