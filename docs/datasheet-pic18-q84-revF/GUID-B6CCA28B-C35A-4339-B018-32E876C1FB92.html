24.5.3 TMR0H

Timer0 Period/Count High Register
Name: TMR0H
Address: 0x319

Bit 76543210 
 TMR0H[7:0] 
Access R/WR/WR/WR/WR/WR/WR/WR/W

Bits 7:0 – TMR0H[7:0] TMR0 Most Significant Counter

ValueNameDescription
