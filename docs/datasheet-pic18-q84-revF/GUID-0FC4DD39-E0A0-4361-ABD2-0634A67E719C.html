41 FVR - Fixed Voltage Reference

The Fixed Voltage Reference (FVR) is a stable voltage reference, independent of VDD, with 1.024V, 2.048V or 4.096V selectable output levels. The output of the FVR can be configured to supply a reference voltage to analog peripherals such as those listed below.

  • ADC input channel
  • ADC positive reference
  • Comparator input
  • Digital-to-Analog Converter (DAC)

The FVR can be enabled by setting the EN bit to ‘1’.

Note: Fixed Voltage Reference output cannot exceed VDD.
