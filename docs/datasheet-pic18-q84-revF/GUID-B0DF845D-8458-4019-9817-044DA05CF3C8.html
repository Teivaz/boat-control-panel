9.7.12 BSR

The BSR indicates the data memory bank of the GPR address.

Name: BSR
Address: 0x4E0

Bank Select Register

Bit 76543210 
   BSR[5:0] 
Access R/WR/WR/WR/WR/WR/W 
Reset 000000 

Bits 5:0 – BSR[5:0] Most Significant bits of the data memory address
