37.5.16 I2CxADR0

I2C Address 0 Register
Name: I2CxADR0
Address: 0x0290

Bit 76543210 
 ADR[7:0] 
Access R/WR/WR/WR/WR/WR/WR/WR/W 
Reset 11111111 

Bits 7:0 – ADR[7:0]  I2C Client Address 0

NameDescription
7-bit Client/Multi-Host modes (MODE = 00x or 11x): ADR[7:1]: 7-bit client address

ADR[0]: Unused; bit state is ‘don’t care’
10-bit Client modes (MODE = 01x): ADR[7:0]: Eight Least Significant bits of first 10-bit address
